**Curated List of SaaS Products & Open-Source GitHub Projects**

## SaaS/Hosted Platforms

- **[TubeBuddy](https://www.tubebuddy.com/)**  
  Browser extension and app for YouTube creators with keyword research, bulk metadata editing, A/B testing, and competitor analysis . Best for bulk channel management and catalog-wide updates .

- **[vidIQ](https://vidiq.com/)**  
  YouTube SEO tool prioritizing research and guidance with keyword search volume, competition scores, outlier detection, and AI-powered daily ideas . Best all-around tool for finding content opportunities and validating topics before publishing .

- **[TubeRanker](https://tuberanker.com/)**  
  Video optimization tool with SEO features, tag generation, channel monitoring, and rank tracking for creators and marketers .

- **[Morningfame](https://morningfa.me/)**  
  YouTube SEO tool providing keyword research and analytics for growing channels .

- **[Semrush](https://www.semrush.com/)**  
  Comprehensive SEO platform with YouTube keyword research, competition analysis, and video ranking tools .

- **[Ahrefs](https://ahrefs.com/)**  
  Keyword research platform with YouTube-specific search volume, keyword difficulty, and Brand Radar for AI visibility . Excellent for finding crossover opportunities between YouTube and Google Search .

- **[RankTracker](https://www.link-assistant.com/rank-tracker/)**  
  SEO PowerSuite component for YouTube rank tracking and monitoring .

- **[KeywordTool.io](https://keywordtool.io/)**  
  Keyword discovery tool generating YouTube autocomplete keywords with search volume across 192 countries .

- **[TubeSpanner](https://tubespanner.com/)**  
  YouTube SEO and channel management tool .

- **[TuBeast](https://tubeast.com/)**  
  YouTube SEO tool for video optimization and ranking .

## Open-Source GitHub Projects

- **[youtube-marketing-skills](https://github.com/adityaarsharma/youtube-marketing-skills)**  
  Open-source agent-agnostic YouTube growth toolkit with 21 AI commands and live channel MCP. Works with Claude Code, Cursor, Codex, Windsurf, Gemini CLI, and any MCP client. Features competitor gap analysis (`/youtube-competitor`), keyword-ranked ideation (`/youtube-ideate`), calendar sequencing (`/youtube-calendar`), and SEO optimization (`/youtube-seo`). Integrates DataForSEO MCP for live keyword volume and YouTube SERP data. Free vidIQ/TubeBuddy alternative .

- **[RankTube](https://pypi.org/project/ranktube/)**  
  Open-source YouTube keyword research tool with browser UI (`rt-ui`). Features relevance ranking based on keyword match quality, channel filtering, and four output modes (urls, details, json, verbose). Uses YouTube Data API v3 with free quota of 10,000 units/day. Exports results for NotebookLM, Claude/ChatGPT analysis, or content auditing .

- **[reach-optimiser](https://github.com/avirajpaul5/reach-optimiser)**  
  Open-source tool to analyze and optimize YouTube video metadata (titles and descriptions) for better SEO and discoverability. Features detailed scoring on SEO factors, AI-powered optimization recommendations via Groq, summary and detailed professional reports, user authentication with Supabase, and session history tracking. React/TypeScript stack .

- **[Youtube-Keyword-Scraper](https://github.com/mod-hamza/Youtube-Keyword-Scraper)**  
  Open-source scraper using Selenium WebDriver to gather video titles, views, recency, and duration for keywords or channels. Retrieves channel subscriber counts and stores data in MySQL for further analysis. Generates reports with keyword and channel insights. MIT licensed .

- **[Evidence-first YouTube Keyword Research](https://github.com/topics/youtube-seo)**  
  Open-source automation with recursive autocomplete, VidIQ All-history curves, AI thumbnail scoring, and Goldmine/GEMmine alerts. Part of 350+ public repositories matching the `youtube-seo` topic .

- **[VAI0](https://github.com/topics/youtube-seo)**  
  AI-powered CLI tool that extracts audio, generates multilingual captions, and creates SEO-optimized YouTube titles and descriptions using Whisper + Ollama .

- **[Advanced YouTube SEO Generator](https://github.com/Avinashricky211/Advanced-Youtube-Seo-Generator-2.0)**  
  Python script optimizing YouTube video SEO via YouTube Data API. Provides recommendations for titles, descriptions, tags, and hashtags to improve discoverability. Part of 350+ repos on the `youtube-seo` GitHub topic .

- **[AI Agent for YouTube Growth](https://github.com/topics/vidiq-alternative)**  
  VidIQ-style keyword/tag research, competitor channel analysis, video SEO, trend discovery, and channel analytics powered by muapi.ai .

- **[YouTube Analytics Chrome Extension](https://github.com/topics/vidiq-alternative)**  
  Free, no-login analytics extension (MV3) with outlier scores, views-per-hour, revenue estimates, monetization detection, and Cloudflare Workers + D1 time-series backend for measured view velocity .

- **[Clipmark](https://github.com/topics/youtube-seo)**  
  High-performance YouTube video processing tool extracting transcripts, timestamps, chapters, tags, and SEO metadata using native YouTube APIs. Built with Next.js, Node.js, Redis, and MongoDB for fast creator insights without AI latency .

**Frameworks for building custom systems**: Combine **youtube-marketing-skills** for AI-powered research and ideation, **RankTube** for keyword relevance ranking, **reach-optimiser** for metadata scoring, **Youtube-Keyword-Scraper** for data collection, and **Ollama + DataForSEO MCP** for live intelligence to build a complete self-hosted YouTube SEO stack.
